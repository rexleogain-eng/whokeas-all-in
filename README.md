# WHOKEAS ALL IN

U.S.-focused ecommerce storefront for WHOKEAS ALL IN.

## Stack

- Next.js 16
- TypeScript
- Vercel
- Neon Postgres
- Pesapal API 3.0 payment integration

## Production

https://www.whokeas.store

## Payments

Pesapal credentials are stored only as Vercel environment variables and are never committed to the repository.
